# Proyecto 1 - Portafolio Personal

## Descripción
Este proyecto es una página web personal creada para presentar mi perfil profesional,
mis habilidades y mis datos de contacto.

## Problema que resuelve
Permite presentar de forma organizada la información profesional de un estudiante
y facilitar que otras personas conozcan sus habilidades.

## Tecnologías utilizadas
- HTML5
- CSS3

## Cómo ejecutar
1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en un navegador web.
